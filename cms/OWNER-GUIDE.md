# Editing the Carlson Gracie website

Studio: https://carlson-gracie-nz.sanity.studio/

## Where to start

- **Coaches:** edit a person’s main photo, name, role, bio and belt details once.
- **Seminar guests:** edit a guest’s photo, name and credentials once.
- **Events:** create dated seminars, competitions and gatherings. Enter the date, venue, photo and booking link. Completed events move to Past events.
- **Academies:** edit the relevant academy page and select its coaches. Cromwell is listed here for page text, photos and search details; its weekly classes are under Academy timetables.
- **Academy timetables:** manage one confirmed weekly schedule for each of the five gyms.
- **Pages:** choose Home, Training, Membership, About, Seminars, Contact or Legal. Sections follow the website order. Edit text directly and open a photo to replace it.
- **Website details:** update the main Queenstown phone number, social links and joining/trial link.

## Show a coach or guest on a page

Open the page’s relevant section. Add a reference to the existing profile; create a profile only if the person is new. Drag the selections to change their order. Removing a selection affects this page only. Publish the page when finished.

## Edit a shared profile

Open Coaches or Seminar guests, select the person, edit and Publish. The profile shows which published pages use it. Each page normally uses the shared values.

Some existing pages used different wording, photos or rank information. These were preserved under **Page-specific details** inside the profile rather than silently standardised. An override takes priority on its named page. Clear an individual override to use the main value, or remove the variation to use all shared values. Confirm rank/name differences before doing this.

## Hide a person

Turn off **Show on website** and Publish to hide that profile from every selected page. Turn it back on to restore the placements. Remove a selection from one page when you only want to change that page. A referenced profile is protected against accidental deletion.

## Weekly academy timetables

Open **Academy timetables** and choose Queenstown, Wānaka, Cromwell, Invercargill or South Canterbury. Working drafts are now in Sanity. Queenstown and Wānaka use times copied from the current website; Invercargill uses its published kids’ times. Cromwell contains a 5 May schedule supplied by Brad that still needs checking with the academy; South Canterbury contains an older 2 February 2025 schedule supplied by Brad. Both must be rechecked with the local teams before they are shown as confirmed. Check every time with the local coach before enabling the public timetable. Add one entry per confirmed weekly class: day, time with am/pm, class name, and optional age or level details. Turn on **Show this timetable on the website**, then **Publish**. Each academy has one master timetable, displayed as readable page text after the site rebuild. The page keeps its existing timetable or confirmation message until a confirmed schedule is published.

For Queenstown, Wānaka and Cromwell, enter a verified public Gymdesk schedule URL in **Live Gymdesk schedule URL** to show a live timetable button below the weekly classes. Queenstown and Wānaka have public links already; Cromwell needs its link confirmed. The live link is a convenience for last-minute changes. Update the weekly classes in Studio when regular times change.

## Publishing

Changes stay in drafts until you Publish. Open the website to check them after publishing; caching and rebuilding can cause a short delay. Publishing a shared profile refreshes the pages that use it. Updating an event does not change the weekly class timetable.

## Editing boundaries

The design and page order are fixed. Video, navigation structure and embedded maps remain source-managed. Weekly class timetables are edited under **Academy timetables**, separately from page copy. Pricing and page-specific FAQs remain with their pages; not every phrase is a shared record. Contact forms and booking links use their existing services.

## Blog posts
Open **Blog posts → Create**. Enter a title, click **Generate** for the article address, choose **News**, **Events**, **Seminars** or **Technique**, and add the introduction, cover image and article. The article editor supports headings, bold, italic, links, lists, quotes and additional images with captions. Add an image description for each photo.

**Publish** makes the article public after the website rebuild finishes (usually a few minutes). Its category controls the filter in the single Blog area; the latest article appears on Home automatically. The article date controls order, not scheduled publishing. Keep unfinished/future articles as drafts. Use **Unpublish** to remove a published article; allow the same rebuild time. Keep the article address unchanged after sharing its link.

Blog posts cover news, event stories, seminars and technique. Continue to use **Events** for dated bookings, times and venue details. Existing placeholder cards are not articles and have not been published as content.
